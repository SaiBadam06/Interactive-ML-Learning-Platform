{# 4. How it works #}

How it works

You name a topic; a language model writes the lesson; you read, run and question it. Generated code and prose can be wrong, so run it and check it against a source you trust. This is a study aid, not an authority.

  • Text — a written explanation at the depth and level you pick.
  • Code — a working Python program, broken into sections beside the prose that explains them, run in your browser with Pyodide.
  • Audio — the same explanation spoken, downloadable as an MP3.
  • Images — generated diagrams of the concept, with the prompts used.
{# 5. Privacy #}

Privacy

Your recently studied topics live in your browser's local storage and never leave it. Programs you run stay in your browser too: Pyodide executes them locally and no code is sent to a server to run.

When login is configured, saved lessons and a per-day generation count are stored against your account. The topics you type are sent to the model provider to generate content. There is no analytics, no advertising and no third-party tracking.

{# 6. Setup #}

Setup

Self-hosting? These are the environment variables read from .env.

  • NVIDIA_API_KEY — required, free at build.nvidia.com
  • SECRET_KEY — signs the session cookie
  • FLASK_ENV, FLASK_DEBUG — local development only
  • SUPABASE_URL, SUPABASE_ANON_KEY — login and saved lessons
  • SUPABASE_SERVICE_ROLE_KEY — server only, for the admin invite page
  • ADMIN_EMAILS, SITE_URL — who may invite, and where invite links point
